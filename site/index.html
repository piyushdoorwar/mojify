Why Mojify

Wayland changed the rules.
Mojify plays by them.

Wayland intentionally blocks apps from typing into other windows. Mojify uses the secure path: copy to your clipboard, then let you paste exactly where you choose.

Get started

Two commands.
One tiny upgrade.

Install the Wayland clipboard helper, then grab Mojify from PyPI. GTK3 already ships with a standard Ubuntu GNOME desktop.

✓ Ubuntu / GNOME ✓ Wayland session ✓ Python 3.8+
Terminal
1 Install the clipboard helper
$ sudo apt install wl-clipboard
2 Install Mojify from PyPI
$ pip install mojify
3 Launch it
$ mojify
✓ That’s it. Now bind mojify to your favorite shortcut.

One last step

Make it yours.

In GNOME, open Settings → Keyboard → View and Customize Shortcuts → Custom Shortcuts. Set the command to mojify and choose a shortcut that feels natural.
