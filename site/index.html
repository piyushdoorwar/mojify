Why Mojify

Wayland changed the rules. Mojify plays by them.

Wayland intentionally blocks apps from typing into other windows, so pickers that fake keystrokes break. Mojify takes the secure path: it copies your emoji to the clipboard, and you paste it exactly where you choose.

The brittle way

Synthetic keystrokes

Tools like xdotool and ydotool try to type the emoji for you. They fight the desktop security model and fail across Wayland apps.

Blocked on Wayland
The Mojify way

Clipboard first

Mojify copies your choice with wl-copy. You stay in control of where it goes: your terminal, browser, editor or chat app.

Works in every app
Get started

Two commands. One tiny upgrade.

Install the Wayland clipboard helper, then grab Mojify from PyPI. GTK3 already ships with a standard Ubuntu GNOME desktop.

Install the clipboard helper

Mojify uses wl-copy from wl-clipboard to put the emoji on your clipboard.

$ sudo apt install wl-clipboard

Install Mojify from PyPI

One small Python package with the emoji set bundled in.

$ pip install mojify

Launch it

Run it once to try it, then bind it to a shortcut so it is always one keystroke away.

$ mojify

Requirements

  • Ubuntu or another GNOME desktop
  • A Wayland session
  • Python 3.8 or newer

Picker will not start?

On a stripped-down system, install GTK3 and PyGObject. If you installed with pip install --user, make sure ~/.local/bin is on your PATH.

$ sudo apt install python3-gi gir1.2-gtk-3.0
Features

Everything you need. Nothing you don't.

Built to feel native, launch quickly, and disappear the second the job is done.

Search that understands you

Find emoji by name or everyday keywords like fire, party or rocket. Search spans every category and updates as you type.

Your recents, remembered

Your most-used emoji stay one tab away, saved locally in your XDG state directory.

Keyboard from start to finish

Open, search, move with the arrow keys and press Enter to copy, or Escape to dismiss without picking.

Native GTK, tiny footprint

Built with GTK3, already present on Ubuntu GNOME. No Electron shell and no heavy runtime.

Made for your desktop

Add Mojify to the GNOME app grid, search and dock with mojify --install-desktop, and remove it just as easily.

Scriptable

--list prints every bundled emoji for your own tools, --stdout prints the pick instead of copying, and --no-notify skips the notification.

One last step

Make it yours.

Bind Mojify to a GNOME custom shortcut so it is there whenever you need it.

  1. Open SettingsKeyboardView and Customize Shortcuts
  2. Scroll to Custom Shortcuts and add a new one.
  3. Set the command to mojify. If that does not work, use the absolute path from which mojify.
  4. Press Ctrl + . as the shortcut, then click Add.
